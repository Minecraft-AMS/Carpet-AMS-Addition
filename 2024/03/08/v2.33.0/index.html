Carpet AMS Addition v2.33.0

 2024/03/08

新增规则

  • 无限耐久（infiniteDurability）

    • 使用物品不会丢失耐久。

  • 欢迎消息（welcomeMessage）

    • 在玩家进入服务器时发送一条自定义消息给玩家。

  • 获取存档大小（commandGetSaveSize）

    • 使用 “/getSaveSize” 命令获取当前存档大小。

修复

  • 修复 Ping命令（commandPacketInternetGroper） 规则可以导致内存起飞爆炸的BUG。#93

  • 修复了一些文本错误。

New Rules

  • infiniteDurability

    • Use items without losing durability.

  • welcomeMessage

    • When players join the server, send them a custom message.

  • commandGetSaveSize

    • Use the “/getSaveSize” command to get the current save size.

Fix

  • Fixing the commandPacketInternetGroper rule can lead to a memory overflow BUG. #93

  • Fixed some text errors.
